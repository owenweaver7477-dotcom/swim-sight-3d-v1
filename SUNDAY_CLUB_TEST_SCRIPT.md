# Swim Sight 3D Sunday Club Test Script

Use this for a 20-30 minute controlled coach test.

## Setup

1. Open `https://swim-sight-3d-v1.vercel.app` on iPad Safari.
2. Add Swim Sight 3D to the Home Screen.
3. Log in with the test coach account or create a new account.
4. Create a club workspace or join with an invite code.
5. Confirm the coach role and club name look correct.

## Core Flow

1. Add one swimmer with squad, main stroke, notes, and optional swimmer/parent email.
2. Open Analyse Video.
3. Select the swimmer.
4. Upload a 5-10 second swimming clip.
5. Choose stroke, camera angle, capture source, and review goal.
6. Preview the video through the app.
7. Send for AI Review.
8. If AI is reliable, review all pending AI findings.
9. If AI is unreliable, continue manual review without fake findings.
10. Pause video and use Coach Draw to mark one frame.
11. Attach or include the annotation in the report.
12. Approve, edit, reject, or add findings.
13. Add coach summary and next focus.
14. Finalise the report.
15. Create a secure shared report link.
16. Open the shared link logged out or in a private browser.
17. Confirm the public report only shows approved content.

## Coach Feedback Questions

1. Could you understand what needed your review today?
2. Was upload and AI Review clear enough on iPad?
3. Did Coach Draw feel usable with finger/stylus?
4. Were AI reliability labels honest and useful?
5. Did the shared report feel parent-ready?
6. What would stop you using this with a real squad next week?

## Pass Criteria

- Login works.
- Invite code join works.
- Swimmer creation works.
- Private video upload works.
- AI Review creates a report or honest manual-review state.
- No fake findings appear on weak pose.
- Coach approval is required.
- Shared report excludes private video URLs and paths.
- iPad Home Screen install opens like an app.
